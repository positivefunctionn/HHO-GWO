# HHO-GWO guide-requested comparison (PSO excluded)

This project snapshot adds deterministic FCFS and Round Robin baselines and runs a balanced synthetic benchmark against BFD, standalone GWO, standalone HHO, the proposed HHO-GWO hybrid, GA, SA, ACO, DE, WOA, ABC and NSGA-II. PSO is intentionally excluded from this comparison per the user's request.

See `docs/HHO_GWO_GUIDE_REQUESTED_NO_PSO_REPORT.md` for results and limitations. The included 10-seed run is preliminary and synthetic; it does not validate real cloud workloads or the BiLSTM model.
